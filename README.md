## 🌟 Project Overview

**EV-TIMES** is a full-stack Electric Vehicle News & Intelligence Platform built from scratch as an internship project. It serves as a centralized hub for EV enthusiasts, industry professionals, and everyday users who want to stay ahead of the rapidly evolving electric vehicle ecosystem.

<div align="center">

| 🌍 Real-World Impact | 🧠 AI-Powered Insights | 📊 Market Intelligence |
|:---:|:---:|:---:|
| Aggregated EV news from trusted sources | AI-driven summaries & trend analysis | Live market stats & EV adoption data |

</div>

The platform addresses a clear gap in the market: **a single destination for all things EV** — news, charging infrastructure, market analytics, and community engagement — with a clean, modern, and responsive interface.

### 🎯 Core Mission

> To democratize access to electric vehicle knowledge by making EV news, market trends, charging data, and AI-powered insights available to everyone in a beautiful, accessible interface.

## ⚙️ Installation & Setup

### Prerequisites

Ensure you have the following installed:

- A modern web browser (Chrome, Firefox, Edge, Safari)
- [Git](https://git-scm.com/) — for cloning the repository
- A code editor — [VS Code](https://code.visualstudio.com/) is recommended
- *(Optional)* [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) VS Code extension for auto-reload

### Clone the Repository

```bash
# Clone via HTTPS
git clone https://github.com/Swati89923/EV-TIMES.git

# Navigate into the project directory
cd EV-TIMES
```

## 🖥️ How to Run Locally

Since EV-TIMES is currently a frontend-only project, no build steps or package installations are required.

### Option 1 — Direct Browser (Simplest)

```bash
# Open the project in your default browser
# On macOS
open index.html

# On Linux
xdg-open index.html

# On Windows (PowerShell)
start index.html
```

### Option 2 — VS Code Live Server (Recommended)

```bash
# 1. Open the project folder in VS Code
code .

# 2. Right-click on index.html in the explorer
# 3. Select "Open with Live Server"
# 4. Browser auto-launches at http://127.0.0.1:5500
```

### Option 3 — Python Simple Server

```bash
# Python 3
python -m http.server 8080

# Visit in browser:
# http://localhost:8080
```

> ✅ No dependencies. No `npm install`. No build process. Open and go.

## 📈 Learning Outcomes

This project has been an intensive hands-on learning journey covering both frontend fundamentals and full-stack development principles.

### 🧩 Frontend Mastery
- Structuring large-scale HTML projects with semantic, accessible markup
- Writing maintainable, modular CSS using custom properties and utility classes
- DOM manipulation, event-driven programming, and component-based thinking in Vanilla JS
- Implementing real-world UX patterns: modals, infinite scroll, search, and filters

### 🔐 Authentication & State
- Understanding client-side auth flows vs server-side sessions
- Managing application state with Local Storage
- Building form validation logic from scratch without external libraries

### 📐 Software Engineering Practices
- Organizing projects with clear separation of concerns (`app.js` vs `auth.js`, modular CSS)
- Writing readable, commented code suitable for team collaboration
- Planning for scalability: designing features with backend integration in mind
- Using Git for version control and maintaining a professional project on GitHub

### 🔮 Full-Stack Fundamentals *(Upcoming)*
- RESTful API design and HTTP methods
- Database modeling and CRUD operations with MongoDB
- JWT-based authentication and route protection
- Deploying applications to cloud platforms
